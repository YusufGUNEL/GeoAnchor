GNSS-denied absolute visual localization

A UAV that finds itself with no GNSS

A drone whose GPS is jammed does not know where it is. Visual odometry never stops answering and always drifts — 2.8 km off by the end of a 74 km flight. Matching the camera to a satellite map never drifts and fails outright on a quarter of frames. GeoAnchor fuses them in a particle filter.

Which flights work, and how you know before flying

Each point is an entire flight. Match rate is measured with the true position known, so it describes the data rather than the algorithm — and it can be computed from the satellite map before the aircraft leaves the ground. Altitude is not the discriminator: the 2572 m flight works and a 551 m one does not.

What happens at night, with a thermal camera

The robustness study says extreme darkness needs a different sensor, not a software fix. So it was measured, on a separate dataset: 26,568 aligned nighttime thermal/satellite pairs over desert, farmland and roads.

The daylight system does not degrade at night, it stops. LoFTR on raw thermal returns zero inliers on 100 frames out of 100. Throwing away appearance and keeping structure recovers a correct fix on a small fraction of frames:

    The same law that decides the daylight flights decides these frames too, and here it is cheaper to check: a structure score computed from the satellite tile alone — no flight, no thermal frame, no matching — predicts which frames will localise better than the inlier count measured after the match.

    Because it is known before matching, it is also a filter. Combined with a second check — accept a fix only where two band-passed representations independently agree — it beats the tuned gate on every axis at once:

    Read this before quoting the night numbers

    All of it is per-frame. The thermal dataset is a grid of aligned tiles from several regions and nights, not a trajectory, so there is nothing for a motion model to integrate and the particle filter was never run on it. This is a predictor and an operating point, not a working night system.
